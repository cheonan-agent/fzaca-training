컬렉션 자료형 : 여러값을 하나의 구조로 담기 위해

- 리스트 [ ]
- 딕셔너리 {key:value}
- 튜플 ( )   변경불가
- 세트 { }  중복불가


### 컴프리헨션 설명

**내포(comprehension)** = 리스트 `[ ]` 안에 for문을 품고 있는 문법

### ` [ 값  for 변수 in 반복대상  if 조건 ]`

- 맨 앞이 최종 결과값, `for`는 반복, `if`는 거르기
- `for + append`를 한 줄로 줄인 것 (새 기능이 아니라 줄여 쓰기)

#### if문은 생략 가능
```python
questions = [ m["content"]  for m in conversation]
```
이렇게 넣으면 전체가 다 들어간다

<br><br>

### 강사님 컴프리헨션 설명

잘 이해가 안되니 for문을 가운데에 두고 날개를 펼치는데, 양쪽 왼쪽 날개와 오른쪽 날개를 펼쳐서

왼쪽에는 실제 리스트에 들어갈 값 오른쪽에서는 조건 오른쪽 날개는 있을수도 있고 없을수도 있다.

```
(왼쪽 날개)리스트에 들어갈 값 (가운데 for문)** if or None **(오른쪽 날개)
```

## 네임 바인딩

```python
a = 1
b = a

a = [1,2,3]

b[0] = 4
print(a)
print(id(a), id(b))
```

## 8. 기본값의 함정 — 리스트를 기본값으로 쓰면 안된다.

```python
def start_message(role, content, conversation=[]):
    conversation.append({"role": role, "content": content})
    return conversation

a = start_message("user", "첫 대화")
b = start_message("user", "새 대화")
print(b)
```

실행결과

```bash
[{'role': 'user', 'content': '첫 대화'}, {'role': 'user', 'content': '새 대화'}]
```
