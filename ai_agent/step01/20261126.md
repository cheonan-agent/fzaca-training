## 모듈과 패키지의 차이
- 모듈 : 파일
- 패키지 : 폴더(디렉토리)

```python
import 패키지.모듈명
from 패키지.모듈명 import 함수, 클래스, 변수 ...
```

import에 . 이 나오면 왼쪽 대상에 접근하는 기호

### alias (as)

## 파일(IO)

- open() 함수, mode **(w,a,r / b)**
- 파일객체 : .read(), .readlines()
- JSON(문자열) : 파이썬 객체 -> JSON **(dumps)**
- JSON - > 파이썬 객체 **(loads)**
