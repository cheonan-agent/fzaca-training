# 5. 여러 데이터를 묶기 — 리스트·딕셔너리·튜플·세트

## 1. 컬렉션이 필요한 이유

질문이 세 개면 변수도 세 개가 필요할까? 대화가 100번 오가면 변수 100개를 만들 수는 없다. 여러 값을 하나로 묶는 그릇을 **컬렉션(collection)**이라고 한다.


| 컬렉션 | 기호	| 특징	| 챗봇에서의 쓰임 |
| --- | --- | --- | --- |
|리스트 **list**	| **[ ]**	| 순서 있음, 바꿀 수 있음	| 대화 (메시지의 목록)|
|딕셔너리 **dict**	| **{키: 값}**	| 이름표(키)로 값을 찾음 | 메시지 하나|
|튜플 **tuple**	| **( )**	| 순서 있음, 바꿀 수 없음	| 함수가 값 | 여러 개를 돌려줄 때|
|세트 **set**	| **{ }**	| 순서 없음, 중복 없음	| 허용된 role 목록|

## 3. 딕셔너리

대괄호로 없는 키를 찾으면 에러가 난다.

```python
bad_message = {"role": "user"}
bad_message["content"]
```

```
KeyError: 'content'
```

들어오는 데이터에 키가 없을 수도 있다면 `get()`을 쓴다. 외부 API 응답을 다룰 때(14장) 특히 중요하다.

## 리스트와 딕셔너리

공: 리스트 [ **"노랑"**, **"파랑"**, **"빨강"**, **"파랑"** ..... ]

빈 딕셔너리(결과) { }

### 공을 하나씩 꺼내기 (반복)
- 리스트에서 차례(순서)대로 꺼내기
- 꺼낸 공 색깔로 결과를 변경
- 예 ) 파란공 -> 결과["파랑"] = 결과["파랑"]+1 (에러)


결과 : 딕셔너리{ **"노랑"**: **1**, **"파랑"**: **2**, **"빨강"**: **1** ...}
